# IEEE24参考结果

reference_results.csv一行对应一个原始24小时样本，sample_id为1—1800。保留目标、最好界、相对gap、耗时、费用分项、独立验解残差及负荷统计。删除仅用于本地运行管理的路径和复用标记，数值字符串保持。

verification.json保存完整覆盖数量、参数、验解阈值、汇总残差与输入/工具身份。1800样本均达到所设0.01%相对gap并通过独立验解；这不是零gap精确最优证明。费用保持原尺度，币种和价格年未确认。

未分发完整变量与原始运行记录，因此本表用于参考比较，不能仅凭总表再次逐约束验算候选。复算可使用共享工具恢复固定来源后执行；独立验解程序与原模型构建器分别实现。
