## 已执行的参考配置

`copt03` 使用 5 线程、随机种子 0、1,800 秒上限和上轮已验候选作为 MIP start。原始模型的 8,378 行基础约束保留，另加 3,720 条由原整数约束推出的爬坡行，形成 12,098 行、9,624 个变量的模型。上轮候选的状态、权重和逐时削负荷用于启动，本发布包保留其哈希，完整候选和运行日志保存在项目工作材料中。运行清单中的代码哈希对应历史运行。公开冷启动入口调整了默认输入路径，模型构建器与爬坡收紧器的字节可直接和历史哈希核对。

记 `q[t]=p[t]-Pmin*u[t]`。机组停运时 `q[t]=0`，故可用 `RU*u[t]` 和 `RD*u[t-1]` 分别收紧第 2 小时起的向上和向下爬坡上界。容量包络使用同一最小开机窗口中的启动或停机事件，上界由事件与当前小时之间的累计爬坡得到。对初始在线机组再用初始出力和累计向上爬坡界收紧。所有行由 [ramp_cuts.py](../../scripts/orlib50/ramp_cuts.py)生成，首小时和末小时的原模型边界仍适用。
