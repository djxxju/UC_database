# 校验报告

每个算例使用`reports/<case_id>/`：

- data_validation.json：结构、字段、输入映射、指定必要条件等实际数据检查结论。
- checksums.sha256：该算例正式交付文件及其使用的规范/工具版本的SHA-256，路径均相对于仓库根目录。

候选可行性及目标重算摘要放results/<case_id>/verification.json，避免与输入检查混写。尚未执行的项目显式标注状态，不生成伪造的通过报告。

逐算例清单不包含全库catalog.json、根README、目录说明或其他算例，新增算例不改变既有清单。它可以包含该算例引用的profile、Schema和程序；修改这些已被引用的文件时，应保留旧版本或明确更新受影响算例的版本与验证记录，不能直接覆盖历史证据。

现有IEEE24复算脚本仍保留其真实执行版本，复算工作目录中的默认报告路径可与正式发布路径不同；最终入库时按本规范归位并更新索引。这里没有声称所有未来模型都已完成适配。
