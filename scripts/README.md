# 全库共享工具

同一工具在全库保留一份，按它明确支持的profile使用。当前六个ieee24程序分别负责：build整理/固定来源恢复、validate数据检查、solve单例求解、check独立候选验算、solve_batch批量/续跑、export汇总。

这些工具目前仅验证RPG Lab IEEE24原B-θ模型，不宣称可直接处理所有新来源。新增来源时先增加相应读取/模型适配并检查，再按入库规范登记能力范围。运行输出、原件恢复缓存和完整变量不自动进入Git，忽略规则见根.gitignore。

代码身份是历史结果证据的一部分。模型/验解代码发生变化后，应在新运行中记录新哈希，不把历史adapter/checker身份替换成当前代码身份。
